# Voice API (Spec B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `POST /api/voice`: a WAV clip in, spoken reply out, driving the existing F.R.I.D.A.Y. agent — STT (whisper.cpp `tiny.en`) and TTS (piper `low`) run in-process via bundled binaries.

**Architecture:** One new blueprint (`pages/voice`) orchestrates: bearer-token auth → parse uploaded WAV → `core.stt.transcribe` (whisper-cli subprocess) → reuse the agent tool-loop via a new non-streaming `agent.run_text` → `core.tts.synth` (piper subprocess) → return `multipart/mixed` (JSON sidecar + reply WAV). The existing streaming web chat (`run_turn`), agent tools, DB, and templates are untouched. STT/TTS binaries + models are vendored under `vendor/voice/`; tests never invoke them (subprocess is monkeypatched).

**Tech Stack:** Flask 3, stdlib `subprocess`/`tempfile`/`hmac`, whisper.cpp (`whisper-cli` + `ggml-tiny.en.bin`), piper (`piper` + `en_US-*-low.onnx` voice). No new pip dependencies.

## Global Constraints

- **No new pip dependencies.** STT/TTS are external binaries called via stdlib `subprocess`; no Python bindings (ponytail).
- **Audio format is 16 kHz mono 16-bit WAV** end to end — whisper's native input, piper's output, the board's format. No resampling anywhere.
- **Auth: shared bearer token.** `Authorization: Bearer <VOICE_TOKEN>`, compared with `hmac.compare_digest` (constant time). **Fail closed:** if `VOICE_TOKEN` config is empty, every request is 401.
- **Endpoint fail-soft on content, fail-hard on protocol:** empty transcript and agent/LLM errors return **200** with a *spoken* fallback reply; only bad/missing token (401), missing/empty audio (400), and oversize audio (413, cap 2 MB) are non-200. Any 200 means "play the audio."
- **Only `/tmp` is writable on Vercel.** All scratch WAVs go through `tempfile` (`tempfile.mkstemp()` / `gettempdir()`), and are deleted after each request.
- **Reuse, don't fork, the agent.** `run_text` shares `_system`, `_args`, `MAX_STEPS`, `dispatch`, and `messages` with `run_turn`. The ~12-line loop body is duplicated (one yields SSE, one returns a dict) — this is deliberate and acceptable; the shared helpers hold the real logic. Do not extract a clever shared generator.
- **Secrets from env**, never in source. `VOICE_TOKEN` from environment; in tests it's a config override.
- **Vendored assets under `vendor/voice/`** are not committed as binaries in this plan (they're large and platform-specific) and are not downloaded in CI. Task 4 documents how to obtain/place them.
- **Design rules retained:** no external CDN, self-host assets, no emoji, Lucide icons.

The suite runs against real Postgres (`TEST_DATABASE_URL` in `.env`, already configured). Run tests with `python -m pytest -q`; if output is swallowed by the RTK hook, use `rtk proxy python -m pytest -q`.

```python
def run_text(user_text: str, client=None) -> dict:
    """Non-streaming sibling of run_turn: run the tool loop, return {reply, actions}.

    Same loop as run_turn but collects instead of yielding (SSE vs dict); the shared
    helpers (_system/_args/dispatch/messages) hold the real logic.
    """
    client = client or DeepSeekClient()
    messages.add("user", user_text)
    actions: list[str] = []
    try:
        for _ in range(MAX_STEPS):
            msg = client.complete([_system(), *messages.to_api()], TOOLS)
            tool_calls = msg.get("tool_calls")
            if tool_calls:
                messages.add("assistant", msg.get("content"), tool_calls=tool_calls)
                for tc in tool_calls:
                    name = tc["function"]["name"]
                    actions.append(name)
                    result = dispatch(name, _args(tc))
                    messages.add("tool", json.dumps(result), tool_call_id=tc["id"], name=name)
                continue
            text = msg.get("content") or ""
            messages.add("assistant", text)
            return {"reply": text, "actions": actions}
        return {"reply": "F.R.I.D.A.Y. couldn't finish that in time.", "actions": actions}
    except LLMError as e:
        return {"reply": _llm_error(e), "actions": actions}
```

"""Speech-to-text via a bundled whisper.cpp binary. No Python bindings (stdlib subprocess)."""
import subprocess
from pathlib import Path

VENDOR = Path(__file__).resolve().parent.parent / "vendor" / "voice"
WHISPER_BIN = VENDOR / "whisper-cli"
WHISPER_MODEL = VENDOR / "ggml-tiny.en.bin"


class STTError(RuntimeError):
    """whisper.cpp failed."""


def transcribe(wav_path: str) -> str:
    """Return the transcript of a 16 kHz mono 16-bit WAV. Empty string if nothing recognized."""
    proc = subprocess.run(
        [str(WHISPER_BIN), "-m", str(WHISPER_MODEL), "-f", str(wav_path), "-nt", "-np"],
        capture_output=True, text=True,
    )
    if proc.returncode != 0:
        raise STTError(proc.stderr.strip() or "whisper failed")
    return proc.stdout.strip()
```

(`-nt` no timestamps, `-np` no progress prints → transcript on stdout.)

"""Text-to-speech via a bundled piper binary. No Python bindings (stdlib subprocess)."""
import subprocess
from pathlib import Path

VENDOR = Path(__file__).resolve().parent.parent / "vendor" / "voice"
PIPER_BIN = VENDOR / "piper"
PIPER_VOICE = VENDOR / "en_US-low.onnx"


class TTSError(RuntimeError):
    """piper failed."""


def synth(text: str, out_path: str) -> str:
    """Synthesize `text` to a WAV at out_path (16 kHz mono). Returns out_path."""
    proc = subprocess.run(
        [str(PIPER_BIN), "-m", str(PIPER_VOICE), "-f", str(out_path)],
        input=text, capture_output=True, text=True,
    )
    if proc.returncode != 0:
        raise TTSError(proc.stderr.strip() or "piper failed")
    return out_path
```

```python
"""Spec B — POST /api/voice: WAV in -> STT -> agent -> TTS -> multipart(JSON, WAV) out."""
import hmac
import json
import os
import tempfile

from flask import Blueprint, Response, current_app, jsonify, request

from core import stt, tts
from pages.friday import agent

voice_bp = Blueprint("voice", __name__)

MAX_AUDIO_BYTES = 2 * 1024 * 1024          # ~60s of 16 kHz mono 16-bit
_BOUNDARY = "friday-voice-boundary"
_EMPTY_STT_REPLY = "I didn't catch that."


def _authorized() -> bool:
    token = current_app.config.get("VOICE_TOKEN") or ""
    if not token:
        return False                       # fail closed: unconfigured ⇒ deny
    header = request.headers.get("Authorization", "")
    prefix = "Bearer "
    sent = header[len(prefix):] if header.startswith(prefix) else ""
    return bool(sent) and hmac.compare_digest(sent, token)


def _multipart(meta: dict, wav_bytes: bytes) -> Response:
    b = _BOUNDARY
    parts = (
        f"--{b}\r\nContent-Type: application/json\r\n\r\n"
        f"{json.dumps(meta)}\r\n"
        f"--{b}\r\nContent-Type: audio/wav\r\n\r\n"
    ).encode("utf-8") + wav_bytes + f"\r\n--{b}--\r\n".encode("utf-8")
    return Response(parts, mimetype=f"multipart/mixed; boundary={b}")


@voice_bp.route("/api/voice", methods=["POST"])
def voice():
    if not _authorized():
        return jsonify({"error": "unauthorized"}), 401

    upload = request.files.get("audio")
    if upload is None:
        return jsonify({"error": "no audio"}), 400
    audio = upload.read()
    if not audio:
        return jsonify({"error": "no audio"}), 400
    if len(audio) > MAX_AUDIO_BYTES:
        return jsonify({"error": "audio too large"}), 413

    in_fd, in_path = tempfile.mkstemp(suffix=".wav")
    out_fd, out_path = tempfile.mkstemp(suffix=".wav")
    os.close(out_fd)
    try:
        with os.fdopen(in_fd, "wb") as f:
            f.write(audio)

        transcript = stt.transcribe(in_path)
        if transcript:
            result = agent.run_text(transcript)
            reply, actions = result["reply"], result["actions"]
        else:
            reply, actions = _EMPTY_STT_REPLY, []

        tts.synth(reply, out_path)
        with open(out_path, "rb") as f:
            wav_bytes = f.read()

        return _multipart({"transcript": transcript, "reply": reply, "actions": actions}, wav_bytes)
    finally:
        for p in (in_path, out_path):
            try:
                os.remove(p)
            except OSError:
                pass
```
